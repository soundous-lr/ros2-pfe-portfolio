03. Guide de Lancement Pas-à-Pas (Pour Évaluateurs)

Exécutez ces commandes dans votre terminal Ubuntu pour démarrer le workspace.

ÉTAPE 01 Installation des dépendances ROS 2

Cloner et résoudre les dépendances manquantes

cd ~/nav2_real_ws && rosdep install --from-paths src --ignore-src -r -y
ÉTAPE 02 Compilation Colcon

Compiler l'ensemble des 5 paquets

colcon build --symlink-install --cmake-args -DCMAKE_BUILD_TYPE=Release
ÉTAPE 03 Sourcing de l'environnement

Charger l'overlay dans votre session Bash

source install/setup.bash
ÉTAPE 04 — SCÉNARIOS DE DÉMO Démarrage complet
1. Simulation Gazebo + Robot Bringup
ros2 launch my_robot_bringup bringup_sim.launch.py
2. Nav2 & Suivi d'Humain Autonome
ros2 launch my_robot_navigation navigation.launch.py
